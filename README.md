## 📖 介绍

本插件为 NoneBot2 提供了 QQ 群精华消息的完整管理功能，支持：

- ✅ 设置精华消息
- ✅ 移除精华消息
- ⏳ 查看精华列表（即将支持）

基于 OneBot V11 协议实现，支持 NapCat、go-cqhttp 等协议端。

## 📦 安装

### 使用 nb-cli（推荐）

```bash
nb plugin install nonebot-plugin-set-essence-msg
